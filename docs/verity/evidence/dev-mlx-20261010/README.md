# Local MLX development integration — executed 2026-10-10

**Status: DEV_ONLY WORKING; production NOT APPROVED.** The authenticated Azaeron API and conversation worker generate with the Mac's loopback MLX-LM 0.32.0 server. The frontend is running at `http://127.0.0.1:14710/ai`. Production inference still requires an approved registry model and independent verifier; the registry has zero entries. Generated chat, summaries and rewrites explicitly carry `accepted=false` or `verification.outcome=UNAVAILABLE` as appropriate. The adapter accepts only `127.0.0.1:8080`, or `host.docker.internal:8080` in an explicitly configured development container. It disables proxy inheritance and redirects, verifies the model ID for every call, bounds input/output/time/concurrency, propagates cancellation, requests Qwen's no-thinking chat template, and strips reasoning fields and `<think>` blocks. It has no hosted fallback. Document Q&A uses bounded lexical passages with offsets and hashes, labeled as limited coverage; large summaries fail closed. No detector or embedding model is implied.
